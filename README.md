# toDoList

Simple TODO list built with React and TypeScript.

## Overview

This project is a learning exercise for building a modern, responsive TODO app with TypeScript, functional components, and state management.

### Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Edit tasks (optional goal)
- Persist tasks to local storage

## Getting Started

### Prerequisites

- Node.js 16+ (or latest LTS)
- npm or yarn

### Install

```bash
npm install
# or
# yarn install
```

### Run in development

```bash
npm start
# or
# yarn start
```

Open http://localhost:3000 in your browser.

### Build for production

```bash
npm run build
# or
# yarn build
```

## Project Structure

- `src/` - source code
- `public/` - static assets
- `.gitignore` - files and folders excluded from version control

## Notes

- Add tests with your preferred framework (Jest + React Testing Library).
